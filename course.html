網頁設計與開發實務

這門課程由淺入深帶領我們認識前端網頁開發技術，從最基礎的 HTML 文件結構出發，逐步進入 CSS 版面設計與 JavaScript 互動效果。透過每週的實作練習，能夠將腦中的設計構想轉化為實際可瀏覽的網站，非常適合初學者建立完整的網頁開發觀念。

課程核心學習單元

  1. HTML5 基礎與語意化標籤：學習網頁骨架、表單、清單、超連結與多頁網站串接。
  2. CSS3 樣式與版面配置：掌握盒模型（Box Model）、Flexbox 與 Grid 排版技巧。
  3. 響應式網頁設計（RWD）：讓網頁在手機、平板與電腦螢幕上都能完美呈現。
  4. JavaScript 基礎互動：為靜態網頁加入動態操作與事件處理功能。

本學期其他修習科目

  • 資料庫系統及設計
  • 海事資訊講座
  • 實務專題(二)
